I'm Di Cui. Data analyst in Boston. 10+ years of reporting and analytics in finance. CFA charterholder.


**Tools:** SQL · Python · SAS · Power BI · Tableau · SPSS


### Projects

- **[budget-analysis-sql-powerbi](https://github.com/dicui-data/budget-analysis-sql-powerbi)** — Massachusetts state budget, FY2005–2027 (Comptroller's CTHRU open spending data, ~48k appropriation records). SQL cleaning and reconciliation checks, budget-to-actual variance and utilization analysis, Power BI dashboards. The 2022–23 utilization dip traces back to pandemic-era reserve accounts, not operations.
- **[operational-risk-powerbi](https://github.com/dicui-data/operational-risk-powerbi)** — Operational risk dashboard for a fictional bank (synthetic data). Power Query consolidation with data quality rules and source reconciliation, star-schema model, exception-first executive dashboard with drill-through. Setting RCSA ratings beside control test results flags a control rated effective that failed testing.
- **[hospital-finance-sql-tableau](https://github.com/dicui-data/hospital-finance-sql-tableau)** — Massachusetts hospital financial performance (Center for Health Information and Analysis, CHIA). Peer benchmarking across hospital cohorts, parent-system reconciliation, Tableau dashboards. *(in progress)*
- **[healthcare-expenditure-sas](https://github.com/dicui-data/healthcare-expenditure-sas)** — U.S. household health care spending, 2023 (Medical Expenditure Panel Survey, MEPS-HC, AHRQ). Analyzed in SAS with the survey's stratified clustered sample design (SURVEYMEANS, DOMAIN, RATIO): zero-expenditure prevalence, spending concentration, payer mix, out-of-pocket burden.
- **[fund-screening-python](https://github.com/dicui-data/fund-screening-python)** — Weekly fund eligibility screening against multi-condition, frequently changing criteria. Built on public fund data, with the rule engine and near-threshold flagging in Python. *(in progress)*
- **[sql-practice](https://github.com/dicui-data/sql-practice)** — worked solutions to SQL practice problems
